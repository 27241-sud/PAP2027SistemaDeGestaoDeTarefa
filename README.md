## Descrição
O projeto consiste no desenvolvimento de um site de gestão de tarefas, direcionado principalmente para estudantes. Tem como objetivo ajudar os estudantes a organizar os trabalhos escolares, os prazos de entrega e as atividades do dia a dia. O site permitirá criar uma conta, iniciar sessão e gerir tarefas, podendo criar, editar, apagar e marcar tarefas como concluídas. Pretende resolver a dificuldade de organização e ajudar a evitar esquecimentos de trabalhos e datas de entrega. Cada tarefa terá um título, uma descrição, uma data limite e uma prioridade.

## Objetivos
* Desenvolver um site simples e fácil de utilizar para a gestão de tarefas.
* Permitir que os estudantes organizem, acompanhem e controlem as suas tarefas e respetivos prazos.
* Aplicar conhecimentos de HTML, CSS, JavaScript, PHP e MySQL no desenvolvimento do projeto.

  ## Funcionalidades

* [ ] Criar conta e iniciar sessão.
* [ ] Criar, editar e apagar tarefas.
* [ ] Marcar tarefas como concluídas e consultar a lista de tarefas.

### Extras (se houver tempo)

* [ ] Filtrar tarefas por prioridade (baixa, média ou alta).
* [ ] Identificar tarefas com o prazo ultrapassado.
